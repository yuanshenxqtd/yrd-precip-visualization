## 1. Open-Meteo（气象数据主源）

官网：https://open-meteo.com/
接口文档：https://open-meteo.com/en/docs
定价页：https://open-meteo.com/en/pricing

### 1.1 基本属性

| 项目 | 核实结果 |
|---|---|
| API Key | **不需要** |
| 注册 | **不需要** |
| 数据来源 | ECMWF ERA5（0.25°，1940 年起）/ ERA5-Land（0.1°，1950 年起）/ 2017 年后为 9km 模型 |
| 许可 | CC BY 4.0，非商业免费，**须署名** |
| 实时性 | 模型分析场，**小时级**，非雷达分钟级观测 |

### 1.2 免费额度（官方定价页原文）

| 维度 | 额度 |
|---|---|
| 每分钟 | 600 次 |
| 每小时 | 5,000 次 |
| 每天 | 10,000 次 |
| 每月 | 300,000 次 |

> 官方对"一次调用"的定义：一次 HTTP 请求通常算 1 次；但**单点超过 10 个气象变量、或时间跨度超过 2 周，会折算为多次调用**。
> 多坐标请求的计费口径官方文档未明写，**本项目按最坏情况（每个点位各计一次）核算**。

### 1.4 额度核算（本项目实际消耗）

采集点位数：**56**
采集频率：**30 分钟/次** → 48 轮/天

| 维度 | 计算 | 消耗 | 占额度 | 余量 |
|---|---|---|---|---|
| 每日 | 56 × 48 | **2,688 次** | 26.9% | **3.7 倍** |
| 每小时 | 56 × 2 | **112 次** | 2.2% | 44 倍 |

**结论：30 分钟采集频率安全，余量充足。**

> 若官方按"HTTP 请求数"计费（批量请求算 1 次），则仅 **48 次/天**，占额度 **0.48%**。

## 2. 阿里 DataV GeoAtlas（行政区划边界）

接口：`https://geo.datav.aliyun.com/areas_v3/bound/{adcode}_full.json`

### 2.1 实测结果

| adcode | 区域 | 返回层级 | 要素数 |
|---|---|---|---|
| 310000 | 上海市 | `district` | **16** |
| 320000 | 江苏省 | `city` | **13** |
| 330000 | 浙江省 | `city` | **11** |
| 340000 | 安徽省 | `city` | **16** |
| | | **合计** | **56** |

### 2.2 要素字段

```json
{
  "properties": {
    "adcode": 340100,
    "name": "合肥市",
    "center": [117.283042, 31.86119],
    "centroid": [117.360447, 31.762594],
    "level": "city",
    "parent": { "adcode": 340000 },
    "childrenNum": 9
  }
}
```

- `center` / `centroid` 直接作为采集点坐标使用
- 四份 GeoJSON 合并为一个 FeatureCollection，即可得到**长三角 56 要素合并地图**

## 4. 旁证数据：为什么必须做历史回放

对 56 个点位近 72 小时真实降水的统计：

```
total_values=4032   nonzero=74 (1.8%)   total_mm=29.4
wettest_point_72h = 温州市  8.8mm
top5 72h accum (mm): [8.8, 7.2, 5.5, 3.9, 2.4]
```

**仅 1.8% 的"小时 × 点位"记录存在降水**，最湿点位 72 小时累计仅 8.8mm。

→ 直接后果：**答辩当日实时大屏极可能全为 0**。因此时间轴回放功能是**必需**而非锦上添花。

## 5. 未采用的数据源及原因

| 数据源 | 未采用原因 |
|---|---|
| 中国气象数据网（data.cma.cn） | 需实名注册与数据申请审批，周期长；接口权限受限 |
| 和风天气 | 需注册 API Key；免费额度有限；分钟级降水属付费能力 |
| 彩云天气 | 分钟级雷达外推需付费 |
| GPM IMERG | 需 Earthdata 账号，为网格栅格数据，与点位统计口径不一致 |
| 中央气象台实况图 | 无开放 API，抓取存在合规风险 |
